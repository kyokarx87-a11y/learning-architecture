# 演習ループ

1問ごとに次の順で進めます。次の問題へ進むまで、この順を崩しません。

1. **出題** — AIは問題文・条件・出典・図だけを示す。ヒントや着眼点、「〜を考えてください」といった誘導は書かない。
2. **回答** — 生徒が答える。判定の根拠は、生徒が書いた文字列だけにする（AIが誘導の途中で出した値を、生徒の解答として扱わない）。
3. **判定**
   - 正解：要点を絞った短い解説。
   - 不正解／わからない：ヒントを**段階的に最大3回**（着眼点 → 式変形の方向 → 手順の直前）。完成した式や結論をAIが書いて確認させない。
   - 3回でも届かない：「解答です。」と宣言し、途中を省略せず解説する。各段階で「なぜこの計算をするか」と「何が分かったか」を添える。
4. **評価の記録** — 教師評価（AI）と自己評価（生徒）を別に記録する（[evaluation.md](evaluation.md)）。
5. **次の問題へ**

## 1回の出題数

| 場面 | 問数 |
|---|---|
| 数学・証明問題 | 3問 |
| 数学・証明以外 | 5問 |
| テスト（全科目） | 10問 |
| 数学以外 | 5問 |

## レベル調整の提案

科目・単元ごとの直近10演習回の正答率から、次の問題のレベルを提案します（その組で10回たまるまで判定しない）。
再演習も1回と数える、演習履歴に基づく指標です。
`ledger.py report`はレベル変更を提案し、実際の問題難度・学年の変更は利用者が行います。
正答は「1回目の解答で正解」（ヒント使用は可）です。

| 直近10問の正答率 | 動作 |
|---|---|
| 70%未満 | 1段階落とす |
| 50%未満 | 2段階落とす |
| 30%未満 | 3段階落とす |
| 0% | 1学年落とす |

今後の拡張として、連続正解数に基づく自動昇段と、問題難度データとの連携を予定しています。
上記は運用上の降段提案のルールです。ヒント込みの正答率と自力正答率を区別してください。
学習効果の確認方法として、ヒントなしの自力正答率、日を空けた再演習、未見問題での確認を想定しています。

## 1つのメッセージに入れてよいもの

①解答の確認 ②その解説 ③次の一歩または次の問題。
「次の2歩」を先回りして示さない（生徒が自分で考える余地を残すため）。
